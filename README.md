# Hospitality Project Management Toolkit

Plantillas y recursos prácticos para organizar proyectos tecnológicos en hoteles, desde el inicio hasta la entrega.

> **English summary:** A practical, vendor-neutral toolkit for planning, tracking and closing hospitality technology projects. The initial release is in Spanish; an English edition is planned.

## ¿Para quién es?

Este repositorio está pensado para jefes de proyecto, integradores, responsables de sistemas, proveedores y equipos técnicos que participan en despliegues de Wi-Fi, redes, GPON, IPTV, telefonía u otras soluciones tecnológicas en hoteles.

No pretende sustituir los procedimientos técnicos, contractuales o de seguridad de cada organización. Su objetivo es ofrecer una base sencilla que cada equipo pueda adaptar.

## Qué encontrarás

| Etapa | Recursos | Objetivo |
|---|---|---|
| Inicio | Acta de inicio e identificación de interesados | Alinear alcance, responsables y expectativas |
| Planificación | Matriz RACI, comunicación y estructura documental | Organizar el trabajo antes de ejecutar |
| Seguimiento | Informe semanal, registro de riesgos y pendientes | Dar visibilidad y facilitar decisiones |
| Cierre | Entrega, acta de cierre y lecciones aprendidas | Comprobar, documentar y transferir el proyecto |
| Ejemplos | Proyecto hotelero ficticio | Mostrar cómo completar las plantillas |

## Cómo utilizar las plantillas

1. Descarga o copia la plantilla que necesites.
2. Sustituye los textos entre corchetes, por ejemplo `[Nombre del proyecto]`.
3. Elimina las secciones que no correspondan a tu proyecto.
4. Acuerda responsables y fechas con las personas implicadas.
5. Guarda cada actualización con fecha y número de versión.
6. Revisa el documento antes de compartirlo.

## Principios del toolkit

- Información clara y útil para tomar decisiones.
- Un responsable y una fecha para cada acción.
- Separación entre hechos, riesgos, decisiones e hipótesis.
- Trazabilidad de cambios y acuerdos.
- Entregas con criterios de aceptación definidos.
- Protección de la información del cliente.

## Seguridad y confidencialidad

Las plantillas no contienen datos de proyectos o clientes reales. Los ejemplos son ficticios.

Antes de publicar o compartir un documento, elimina credenciales, direcciones IP, planos, números de habitación, números de serie, presupuestos, contratos, datos personales y cualquier información protegida por acuerdos de confidencialidad.
